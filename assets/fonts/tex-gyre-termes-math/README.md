# TeX Gyre Termes Math

Math companion for TeX Gyre Termes, used for the MathML output of Typst's
HTML export. The font supplies the OpenType MATH table and the Unicode math
alphanumerics that TeX Gyre Termes itself does not contain.

- Version: 1.543 (2016-05-19)
- Source: <https://www.gust.org.pl/projects/e-foundry/tg-math>
- Downloaded from: <https://mirrors.ctan.org/fonts/tex-gyre-math/opentype/texgyretermes-math.otf>
- Web format: `woff2_compress texgyretermes-math.otf`
